# OpenLedger

A governed Apache Iceberg lakehouse over NYC 311 Service Request data — watermarked
incremental ingestion, a dbt star schema, layered data quality (contracts, unit tests,
Soda distributional checks, five operational anomaly detectors, a live scorecard), a
MetricFlow semantic layer with correctness rules enforced at the query-generation
level, and a public dashboard.
